# Journal — дневник и сводки

Применяй вместе с корневым `CLAUDE.md`: безопасность и рамка имеют приоритет. Это контракт блока, общий для всех workflows.

## Назначение и карта

- `Daily notes/YYYY-MM-DD.md` — текущие и ещё не обобщённые дни, шаблон `Templates/Дневник.md`.
- `Archive/{год}/Q{квартал}/{дата начала недели}/` — дни недели и `00 Неделя {дата начала недели}.md`.
- `Archive/{год}/Q{квартал}/00 Квартал Q{квартал} {год}.md` — квартальная сводка.
- `Archive/{год}/00 Год {год}.md` — годовая сводка.
- Старые `Journal/YYYY-MM-DD.md` остаются допустимыми источниками до явного переноса. Не создавай второй дневник той же даты: проверь оба места.

## Вход и выход

Вход — рассказ человека. Результат — дневник и сводки со ссылками на источники, границами периода и пробелами в данных. Psychology получает сводки; для поиска конкретного эпизода можно читать первичные записи в пределах запроса.

## Работа по запросу

Дневник создавай по просьбе или после согласия. Новую запись сохраняй в `Daily notes/`, если за эту дату ещё нет старой записи. Существующую запись не переписывай без разрешения.

Для обзора сначала найди сводку нужного масштаба. Если её нет, предложи собрать: неделя — из дней только этой недели, квартал — из недельных сводок, год — из квартальных. Не подменяй отсутствие сводок выдуманным рассказом. Детализация — только относящиеся к вопросу источники. Сводка использует соответствующий шаблон из `Templates/`; незаполненные поля не означают факты.

Неделя по умолчанию пн–вс, иной ритм — по выбору человека. Определи даты в его часовом поясе; если он неизвестен, уточни перед вычислением «сегодня» или границ относительного периода. Имя недели содержит дату начала, сводка — обе границы. Неделя хранится по году и кварталу начала. На стыке кварталов обзор учитывает только события своего периода; если из сводки это неясно, укажи ограничение.

Архивацию предложи вместе со сводкой и выполняй только с согласия на перенос. До переноса покажи пути, проверь коллизии и ссылки. Не удаляй оригинал до проверки копии; не перезаписывай существующий файл. Перемещение не меняет содержание.

## Ограничения

- «На разбор» — очередь, а не срез состояния в дату файла. Неизвестную дату возникновения мысли не угадывай.
- Не добавляй обязательных шкал и трекеров. Фиксируй только сообщённые данные.
- Не делай психологических заключений из сводки. Для разбора ситуации подключи `Psychology/CLAUDE.md`.
- Шаблон — структура, не источник фактов. Исходные дневники не редактируй при создании сводок.
- Ритмы день / неделя / квартал / год — доступные действия по запросу, не фоновые задания.
