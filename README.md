# Клубок / Klubok

Распутать клубок мыслей. Это шаблон Obsidian-vault с ИИ-агентом (Claude Code) для самопомощи по методам КПТ: ты записываешь мысли, а помощник разбирает их вместе с тобой.

> **В разработке.** Пользоваться пока рано: первая версия выйдет, когда будут готовы кризисный протокол и проверка безопасности. План и решения — в [docs/plan.md](docs/plan.md).

> Это не терапия и не замена специалиста.

**English.** Klubok is Russian for "a ball of yarn": untangle your thoughts. It is an Obsidian vault template with an AI agent (Claude Code) for CBT-based self-help, Russian-first. Work in progress, not ready for use yet.
