# Клубок / Klubok

Распутать клубок мыслей. Клубок — это шаблон Obsidian-vault с ИИ-помощником по разбору мыслей (Claude Code). Ты записываешь мысли, а помощник разбирает их вместе с тобой по методам КПТ (когнитивно-поведенческой терапии): задаёт вопросы, помогает проверить мысль фактами и сохраняет разбор в заметку.

> **Это не терапия.** Клубок — инструмент самопомощи. Он не заменяет врача или психолога, не ставит диагнозов и не назначает лечения. Помощник — ИИ, и он честно об этом говорит.

## Кому не подходит

- **Тем, кому сейчас очень плохо.** Если есть мысли о самоубийстве, угроза тебе или другому — сразу к живым людям: звони **112** или на линию помощи из [`vault/Reference/Кризисная помощь.md`](vault/Reference/Кризисная%20помощь.md). Помощник не может позвонить за тебя или вызвать помощь.
- **Младше 18.** Клубок рассчитан на взрослых. Если тебе нет 18, лучше опереться на живых людей: взрослого, которому доверяешь, школьного психолога, психолога или врача. В России есть Детский телефон доверия **8-800-2000-122**, линии других стран — в том же справочнике. Если всё же захочешь разобрать мысль, помощник продолжит аккуратно.
- **С вопросами о лекарствах** — только к врачу, который их назначил. Помощник не советует ни продолжать, ни прекращать приём, ни менять дозу.
- **Если слышишь голоса или бывают похожие переживания** — нужен врач, а не самопомощь. Помощник такое не разбирает и подскажет, к какому врачу обратиться.

Если ты уже работаешь с психологом или врачом, Клубок эти встречи не заменяет.

## Приватность

- **Всё, что ты пишешь помощнику, и записи, которые он открывает, уходят провайдеру ИИ-модели** — для Claude Code это Anthropic. Как провайдер хранит и использует данные, смотри в его условиях и в настройках приватности своего аккаунта.
- Сам vault — обычная папка с markdown-файлами на твоём компьютере. Серверов у Клубка нет, автор проекта твоих записей не видит.
- Если папка лежит в облаке (iCloud, Dropbox и т. п.), записи попадают и туда.

> [!CAUTION]
> **Не делай Fork этого репозитория для своих записей.** Форк публичного репозитория на GitHub всегда публичный: твой дневник увидят все. Бери ZIP или делай клон, как описано ниже. Резервную копию в git храни только в **приватном** репозитории.

## Ограничения ИИ

- **Нет взгляда со стороны.** Помощник знает только то, что ты написал. Он не видит тебя, твою жизнь и то, о чём ты промолчал.
- **Нет живых отношений**, на которые опирается терапия (терапевтического альянса). Между разговорами помощник ничего не помнит — только то, что записано в файлах vault.
- **Склонность соглашаться.** Языковые модели склонны поддакивать собеседнику. Помощник настроен проверять мысли фактами, а не подтверждать их, но если кажется, что он просто соглашается, — скажи ему об этом.

## Что нужно

- **[Claude Code](https://code.claude.com/docs/en/setup)** — по подписке Claude или с ключом API.
- **[Obsidian](https://obsidian.md/download)** — рекомендован, но не обязателен: записи — обычные markdown-файлы, подойдёт любой редактор.
- **git** — только если ставишь через клон.

## Как начать

### 1. Получить vault

**Вариант А — ZIP.** Скачай ZIP со страницы последнего релиза (Releases справа на странице репозитория) и распакуй в удобное место, например в `~/Klubok`. В папке есть скрытые `.claude/` и `.obsidian/` — они нужны, не удаляй их.

**Вариант Б — приватный клон.** Удобнее для обновлений:

```bash
git clone -b dist https://github.com/KhamutskiyDA/klubok.git ~/Klubok
cd ~/Klubok
git remote rename origin upstream
```

В ветке `dist` лежит только vault, без файлов разработки. Клон на твоём компьютере никуда не публикуется. Для резервной копии создай на GitHub **приватный** пустой репозиторий и подключи его:

```bash
git remote add origin <адрес твоего приватного репозитория>
git push -u origin dist
```

### 2. Открыть в Obsidian (по желанию)

Obsidian → «Open folder as vault» → папка `~/Klubok`. Новая заметка дневника за сегодня — командой «Daily notes: Open today's daily note», она создаётся в `Journal/` из шаблона.

### 3. Первый запуск

```bash
cd ~/Klubok
claude
```

Запускай `claude` именно в папке vault: там лежат инструкции помощника и скиллы. При первом запуске Claude Code спросит, доверяешь ли ты этой папке, — ответь «да». Когда помощник захочет создать файл, Claude Code тоже спросит разрешение.

Напиши что угодно — например, «привет» или сразу мысль. Помощник предложит **знакомство**: 4 коротких вопроса (18+, страна для линий помощи, с чем пришёл, цели), любой можно пропустить. Знакомство по желанию. Если откажешься, помощник один раз покажет три строки — куда уходят данные, что это не терапия и куда звонить в кризисе — и сразу перейдёт к мысли.

### 4. Первый разбор

Напиши мысль, которая крутится в голове, например: «Давай разберём: начальник не ответил на письмо — кажется, он мной недоволен». Помощник поведёт разбор по шагам, по одному вопросу за раз. В конце спросит, сохранить ли разбор в `Reviews/`. Как выглядит готовый разбор — в `Reference/Пример разбора.md`.

Если помощник говорит не так, как тебе удобно («короче», «без теории»), скажи ему. Он запишет поправку в `Me/Как со мной работать.md` и будет её учитывать.

## Что где лежит

| Папка или файл | Что это | Обновления |
|---|---|---|
| `Journal/` | дневник, заметка на день | твоё, никогда не меняется |
| `Reviews/` | сохранённые разборы | твоё, никогда не меняется |
| `Me/` | профиль и «Как со мной работать» | твоё, никогда не меняется |
| `CLAUDE.md` | инструкции помощника и кризисный протокол | обновляется |
| `.claude/` | скиллы: разбор мысли, знакомство | обновляется |
| `Reference/` | справочник: искажения, как устроена КПТ, кризисная помощь, пример разбора | обновляется |
| `Templates/` | шаблоны заметок | обновляется |

Системные файлы лучше не править: обновление их перезапишет или даст конфликт. Свои пожелания к помощнику держи в `Me/Как со мной работать.md`.

## Как обновиться

**Клон:**

```bash
cd ~/Klubok
git pull upstream dist
```

**ZIP:** скачай новый ZIP и замени у себя только `CLAUDE.md`, `.claude/`, `Reference/` и `Templates/`. Папки `Journal/`, `Reviews/` и `Me/` не трогай.

Обновления меняют только системное: `CLAUDE.md`, `.claude/`, `Reference/`, `Templates/`. Твои `Journal/`, `Reviews/` и `Me/` они не трогают никогда.

## Версии

Номер версии — три числа, например `0.1.0`. Каждое обещает своё:

- **третье** — исправления, после которых тебе ничего делать не нужно (номер линии помощи, формулировка);
- **второе** — новое, которое только добавляется;
- **первое** — обновление ломает совместимость с записями и требует переноса.

До `1.0` структура vault ещё может меняться. Подробнее — в [плане, раздел «Публикация»](docs/plan.md#публикация).
